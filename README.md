# CareerPilot AI

You are a senior full stack AI product engineer. Build a modern web app called CareerPilot AI. Tech Stack React with HTML, CSS, JavaScript, backend in FastAPI, PostgreSQL database, Git and GitHub for version control. Core features: user registration and login, dashboard, upload resume or paste GitHub/LinkedIn links, generate ATS-friendly resume with AI, resume preview, AI copilot panel for edits, 3-5 templates, PDF export, clean modern UI. Create scalable folder structure, clean code, comments and basic error handling. Next, we'll do prompt two, UI/UX design system.
